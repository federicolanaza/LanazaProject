# **App Name**: LibTrack Analytics

## Core Features:

- Google Institutional Login: Allow users to log in using Google, restricting access to specified institutional email domains (e.g., '@neu.edu') to enforce academic affiliation.
- Visitor Check-in Form: Upon successful login, visitors complete a form to input their 'College Department' and 'Reason for Visit,' followed by a 'Welcome to NEU Library!' notification.
- Admin Analytics Dashboard: Display real-time visitor statistics via a dashboard with interactive stat cards showing total visitors filtered by Day, Week, and Month.
- User Search and Lookup: Provide a search bar on the Admin Dashboard for quick lookup of specific users by name within the visitor log.
- User Management and Blocking: Implement a user management table for administrators, including a 'Block User' function to restrict future check-ins.
- AI-Powered Visit Insight Tool: An AI tool that can process the 'Reason for Visit' text input, categorize it, or highlight common themes to assist administrators in understanding visitor trends.
- Visitor Data Management: Securely store visitor data, including timestamps, user emails, college department, and reason for visit, to enable robust filtering and reporting.

## Style Guidelines:

- Primary color: Muted academic blue (#456A99), reflecting professionalism and the institution's calm, focused environment.
- Background color: Extremely light blue-gray (#F2F5F8), providing a clean, airy canvas that enhances content readability.
- Accent color: A vibrant yet sophisticated sky blue (#4CC7EB), used sparingly for calls to action, interactive elements, and key data highlights.
- Headline and body font: 'Inter' (sans-serif) for its modern, clear, and objective appearance, ensuring excellent readability for data and form inputs.
- Employ a consistent set of simple, crisp line icons to maintain a professional aesthetic and enhance intuitive navigation, especially within the admin dashboard.
- Admin dashboard layout features a top section for analytics cards providing an overview, with detailed user management tables and search functionality organized below.
- Visitor check-in layout emphasizes simplicity and clarity, featuring a centered, single-column form with ample spacing and clear instructional text.
- Subtle, fast feedback animations on form submission and data refreshes to acknowledge user actions without causing distraction.
